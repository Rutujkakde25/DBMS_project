About AlumniConnect

Project Overview

AlumniConnect is a full-stack University Alumni Networking Management System built as a DBMS college project. It demonstrates relational database design, SQL queries, normalization, and web application development.

Technology Stack

Frontend

HTML, CSS, JavaScript

Backend

Python Flask

Database

MySQL 8.0

Auth

Flask Sessions + Werkzeug

DBMS Concepts Demonstrated

  • ✅ Normalized schema (1NF, 2NF, 3NF)
  • ✅ Primary keys, foreign keys, UNIQUE constraints
  • ✅ INNER JOIN, LEFT JOIN, multiple joins
  • ✅ Aggregate functions: COUNT, AVG, MIN, MAX
  • ✅ GROUP BY with HAVING clause (subquery)
  • ✅ SQL Views for alumni directory and jobs
  • ✅ Stored Procedure for filtered alumni search
  • ✅ Trigger to validate mentorship requests
  • ✅ Indexes on search columns
  • ✅ Transactions for multi-table operations
  • ✅ Parameterized queries (SQL injection prevention)
